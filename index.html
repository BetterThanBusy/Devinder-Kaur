Selected work

Career Intelligence Agent

A multi-agent career counsellor that turns someone's experience, skills and goals into a personalised six-month plan.

  • Python
  • FastAPI
  • Railway
  • Multi-agent
What I built
A planner, seven specialist agents (profile, market, gap, leverage, paths, action, insight) and a critic that reviews the output in a loop.
Why it's efficient
Only one agent reads the full resume; the rest work from a compact summary. The loop stops at 85% confidence, four rounds or 5,000 tokens per run.

UAE Credit Card Intelligence

Ranks UAE credit cards by estimated net annual value for a given spending profile and builds the best two-card strategy.

  • Python
  • FastAPI
  • PostgreSQL
  • Streamlit
What I built
A deterministic calculation engine for rewards, fees, caps and eligibility. The language model only explains the result; it never does the maths.
Why it's trustworthy
Every card rule comes from the issuer's official documents, with source and version tracked. Anything unverifiable is marked unknown, not guessed.

Customer Intelligence Engine

Predicts which customers will generate the most future revenue, so marketing budget goes where it pays back.

  • Python
  • scikit-learn
  • CLV
  • Churn
What I built
A modular churn and customer-value pipeline on the UCI Online Retail II dataset: 4,966 customers, 180-day prediction window.
Result
The top 10% of customers by predicted value captured 69.9% of actual future revenue. Error fell from £886 (baseline) to £617 per customer.

How I work

Every project follows the same path, and it ends with an honest statement of what the model can't tell you.

  1. Business problem What decision needs to change?
  2. Data What do we actually know?
  3. Prediction What is likely to happen?
  4. Explanation Why does the model think so?
  5. Action What should the team do?
  6. Outcome How will we measure it?
  7. Uncertainty Where could it be wrong?
